# 보카고양 화면 분석 (2026-11-06)

영신 지적(26.11.06): "아니 디자인왜이래 보카고양분석해옵시다", "색상은 바뀌어도 돼 다만 고양이만큼은 이런놈이 아니라구", "그 고양이는 사악한 고양이야", "보카고양 깃헙을 들어가서 개발일지등을 정독하고 옵시다".

첫 시제품은 보카고양 화면을 보지 않고 만들었다. 밝은 크림색 바탕에 Claude가 새로 그린 주황 고양이였다. 시리즈 틀에서 벗어났고, 무엇보다 고양고양이가 아니었다. 그래서 아래를 읽고 정리했다(읽기만 했다).

- 개발일지 '보카고양 이야기'(Claude Docs, rev 198) 전체
- 보카고양 UI_STANDARD, PRINCIPLES, WORK_LOG 목차
- 고양이 대사 브리핑(`pipeline/fable/cat/CAT_BRIEF.md`)·고양체 스타일 가이드(`style_guide.md`)
- history/의 9월 데스크 설계 원문
- 보카고양 FABLE·탄고고양 五十音의 실제 화면(390px 캡처)과 CSS

## 1. 고양고양이

- **고양시 마스코트를 닮은 흰 고양이, 마마마 큐베식 계약자, 속은 영신초이**(데스크 설계 원문 26.9.1). 겉은 귀엽고 속은 사악하다. 영신: "고양이는 네 적수가 아니야. 츤데레 싸이코일 뿐이라고."
- **그림은 코드로 그린 30×33 픽셀 도트**다. 칸 하나가 SVG 사각형이고, 650칸이다. 엔딩 드론이 650대인 까닭이다. 분홍 귀, 볼터치, 분홍 입, 오른쪽 아래 금방울이 있다.
- **표정 7종**: normal(홈), evil(문제를 기다릴 때), win(정답), rage(오답), blank(빈손 시간 초과), sour(치다 만 시간 초과), wicked(힌트). 9월 14일 영신: "지금 고양이의 모든 게 마음에 드니 표정을 '추가'만 할 것".
- 대사는 고양이가 있는 곳의 말풍선에서만 한다. 이름표 '고양고양이'는 분홍이다. 화면 맨 밑 알림은 없다(26.10.13).
- 보카고양과 탄고고양의 그림 자료는 바이트까지 같다(표정 7종 해시 대조). 발음고양은 이 자료를 그대로 쓴다(`assets/cat/goyang-cat.json`).

## 2. 화면의 뼈대

| 자리 | 보카고양 | 발음고양에서 |
|---|---|---|
| 바탕 | 밤하늘. 보라 세로 그라데이션 + 분홍·청록·민트 빛 번짐 + 깜빡이는 별 | 그대로 |
| 판 | 진보라 판, 2px 보라 테두리, 둥근 모서리 14px, 그림자 없음 | 그대로 |
| 머리줄 | 제목(금빛 강조) + 네모 아이콘 단추 | '발음고양' + 홈 단추 |
| 고양이 줄 | 고양이 그림 + 분홍 테두리 말풍선 | 그대로 |
| 목록 | 2열 타일. 끝낸 것은 금빛 테두리, 다음 것은 점선 잠금 칸("🔒 … 끝내면 열려") | 묶음 타일 |
| 큰 단추 | 금빛 입체 단추 | 그대로 |
| 문제 카드 | 머리줄에 시간 막대(연보라)와 고양이(누르면 제출), 말풍선은 막대 자리에 뜸 | 머리줄에 진행 막대와 고양이(표정만). 발음고양은 시간 제한을 두지 않았다(아래 '정할 것') |
| 정답 | 하트가 터지고 콤보, 그 자리에서 정답이 열림 | 하트·콤보 |
| 학원 소개 | 들어오는 화면 맨 아래 "STUDY1 국어 블로그 ›" | 처음 화면에 같은 줄 |

색은 영신이 바꿔도 된다고 했다. 시리즈로 알아보게 바탕·판·고양이 줄은 같게 두고, 발음고양은 소리를 청록(--cyan)으로 칠한다: IPA 기호, 파형, 울림. 강조(대상 기호, 지도 불빛)는 금빛이다.

## 3. 개발일지에서 화면에 걸리는 교훈

- **빛은 단어보다 밝지 않다.** 9월 13일 하트 빛이 글자를 덮어 "회색 때"가 됐다. "어두운 배경 위에서 반투명 채움은 빛이 아니라 때가 된다."
- **연출보다 집중.** 남은 시간을 '도망치는 쥐'로 그렸다가 "시선을 뺏네"로 걷어냈다.
- **그림자와 광원은 걷어냈다**(9월 12~14일 화면 재설계).
- **폰 한 손으로 끝까지.** 답을 확인해도 키보드가 내려가지 않고, Enter·Space로 넘어간다.
- **이미 하던 진도는 빼앗지 않는다.** 저장 키는 한번 정하면 바꾸지 않는다(FABLE은 지금도 `goyang-hoe-seoul-v1`).
- **시간 종료는 오답이 아니다.**

## 4. 정할 것 (영신)

- 문제마다 시간 막대를 둘지. 보카고양은 두고, 시간이 끝나도 오답이 아니다. 발음고양은 듣기가 중심이라 지금은 두지 않았다(Claude 의견: 다시 듣기를 마음껏 하게 하려면 없는 쪽이 낫다).
- 콤보 하트 말고 퍼펙트 포효·장미 복습·돌파 축하 같은 시리즈 연출을 어디까지 가져올지. 공통 기능은 보카고양이 본가라, SHARED.md 절차로 가져온다.
